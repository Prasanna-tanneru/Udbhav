# JANSETU AI — Frontend Demo Edition

This package is intentionally **frontend-only**. Firebase, Firestore, Cloud Functions, Node/Express API code, service-account requirements and backend environment configuration have been removed.

## Run
```bash
npm install
npm run dev
```
